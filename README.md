### How I work

- **Solo founder-operator.** I run three companies and write the internal tools myself with Claude Code; outsourcing only for native mobile layers.
- **Wiki-first.** Every company has a private Obsidian vault on GitHub (`*-wiki`) that feeds the product specs. Decisions get written before they get built.
- **Domain over code.** 20 years in classical voice (Seoul National University, Mannes), MBA (Korea University). The acoustic models in MUZLY come from what I know about singing, not from a dataset I bought.
